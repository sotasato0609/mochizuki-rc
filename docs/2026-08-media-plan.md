## 3. 8月の戦略 — 3本柱

### 柱① エリアを「地元」に戻す

視察プレーは**ご来場が前提**です。遠方からの参加はハードルが高く、実際に第1期で唯一の遠方（神奈川県）からのお問い合わせは「自宅から遠方のため、まずは資料をもとに検討したい」というご返答でした。

**8月はゴルフ場から半径50〜80km圏を主戦場とします。** 長野県東信（佐久・小諸・上田・軽井沢・御代田）と群馬県西部をカバーします。

東京は第1期に6件の実績があるため停止せず、**別枠に分離**してエリア別の成果を測れる形にします。

### 柱② 訴求を「視察プレー」に全面切り替え

8月30日という期限があるため、**期限と価格を前面に出したクリエイティブ**へ差し替えます。

- 「視察プレー受付は**8月30日まで**」
- 「平日8,000円 / 土日祝12,000円（1Rセルフプレー・昼食代込み）」
- 「入会金880,000円・**限定30口**」

### 柱③ 検討中の方を取りこぼさない（リターゲティング強化）

入会金88万円の商材は検討期間が長く、複数回の接触が前提です。

直近30日の実績では、**リターゲティングのクリック率は2.89%と、興味関心層（1.84%）の1.57倍**です。LP到達率も上回ります。**それにもかかわらず、予算配分は9%にとどまっています。**

接触回数（フリークエンシー）も2.12回と低く、高額商材としては不足しています。**8月はリターゲティングの比率を20〜25%へ引き上げます。**

## 5. 8月配信までに実施する改善（追加費用なし）

配信設計と同時に、以下を8月1日までに実施します。**いずれも追加費用は発生しません。**

### ① LPフォームを軽くする

7月は11名が入力を開始しながら、**送信完了が0件**でした。第1期のフォームと比較すると明確に重くなっています。

| 項目                       | 第1期    | 現行                                | 8月までの対応            |
| -------------------------- | -------- | ----------------------------------- | ------------------------ |
| 生年月日                   | 項目なし | **必須**（年・月・日の3プルダウン） | **削除または任意化**     |
| 性別                       | 項目なし | **必須**                            | **削除または任意化**     |
| メールアドレス             | 任意     | 必須                                | 電話番号とどちらか必須へ |
| お問い合わせ種別「その他」 | あり     | なし                                | **復活**                 |
| 必須項目数                 | —        | 11種類（全22項目）                  | **7種類程度へ**          |

### ② DV360の配信面を整理する

7月1日から停止中のため、**再開のタイミングで設定できます。**

2026年5〜6月の実績では、クリック率6.51%（ディスプレイの通常は0.1〜0.5%）に対し、**サイト到達率は15.9%**でした。買ったクリックの84%がサイトに届いていません。

| 配信面                 | クリック | クリック率 |       **サイト到達率** |
| ---------------------- | -------: | ---------: | ---------------------: |
| trilltrill.jp          |    7,574 |       8.5% |              **18.5%** |
| SmartNews（iOSアプリ） |    4,261 |  **18.0%** | 77.6%（**滞在0.9秒**） |
| mamastar.jp            |    1,206 |       5.1% |               **4.1%** |

**クリック率5%超の配信面が65面あり、クリックの61%・配信費の47%を占めています。** これらを除外し、最適化目標を「クリック重視」から変更します。

一方でMILE mobile（Androidアプリ）は滞在28.7秒と良質です。**一律除外ではなく面ごとの選別**を行います。

### ③ Google広告から指名検索を分離する

P-MAXの検索クリックの**70%が指名検索**（「望月リソルゴルフクラブ」等）でした。指名検索は自然検索でも到達できるため、その分の予算を新規開拓に振り向けます。

### ④ コンバージョン計測を広告に接続する

現在、GA4で計測しているお問い合わせがGoogle広告・Meta広告に連携されていません。**8月の成果を正しく測るため、配信開始前に接続します。**
