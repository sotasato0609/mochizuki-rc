## 1. 提案の一言

> **「予算を増やす」提案ではなく、「予算の向き先を変える」提案です。**
> 成果の53%を生んでいる地元に配信を戻し、視察プレーが終わる8月30日までに刈り取ります。

---

## 2. なぜ今、8月なのか

**視察プレー期間が8月30日で終わります（残り40日）。**

視察プレーは「プレー後15分の商談」まで設計された会員獲得の最終導線です。**8月は、この期限を訴求できる最後の月**であり、逃すと次シーズンまで同じ訴求はできません。

したがって8月は通常月の延長ではなく、**期間限定オファーの刈り取り月**として設計します。

## 5. 章②：3つの課題（提案の核）

### 課題1｜配信エリアが広すぎる

- 第1期の成果19件のうち、**53%がゴルフ場から半径50〜70km圏**（長野県東信＋群馬）
- しかし7月の集客は、長野16.7%・群馬2.6%で**合計19%**
- Metaのエリア設定と成果は月次で対応。**半径50km前後の月＝計12件／3都県に広げた7月＝0件**
- 最良月は2026年3月（半径48〜49km・**5件・獲得単価¥50,000**）

### 課題2｜検討中の方への再接触が足りていない

- 入会金880,000円・年会費38,500円は**検討期間が長い商材**。第1期でも「まずは資料をもとに検討したい」「視察してから決めたい」という声が複数
- リターゲティングのクリック率は**2.89%**で、興味関心層（1.84%）の**1.57倍**。LP到達率も上回る
- **それにもかかわらず予算配分は9%**、接触回数は**2.12回**にとどまる
- 月11,700人がサイトを訪れているが、**その大半に再接触できていない**

### 課題3｜配信面の質にばらつきがある

- DV360：クリック率11.3%、**サイト到達率15.9%**（買ったクリックの84%が未到達）
- クリック率5%超の面が65面あり、**クリックの61%・配信費の47%**を占める
- 一方、LINEヤフー（Yahoo!面）は**クリック率0.12%・到達率43.0%**と健全

## 6. 章③：3つの打ち手

| #     | 打ち手                             | 内容                                                                             | 費用         |
| ----- | ---------------------------------- | -------------------------------------------------------------------------------- | ------------ |
| **1** | **エリアを地元に戻す**             | 半径50〜80km圏を主戦場に。東京は別枠に分離して成果を分けて測る                   | **追加なし** |
| **2** | **検討層への再接触を強化する**     | リターゲティング比率を9%→20〜25%、接触回数4〜5回へ／カスタムオーディエンスを拡張 | 予算内       |
| **3** | **配信面を整理して媒体構成を戻す** | DV360は65面を除外して再開／Google広告を第1期水準へ回復／LINEヤフーを再開         | 下記         |

あわせて実施（いずれも追加費用なし）：

- クリエイティブを**視察プレー訴求（8/30まで・平日8,000円）**へ全面差し替え
- **LPの入力導線を最適化**（EFO。入力項目を絞り、検討初期の方が申し込みやすい形へ）
- Google広告から**指名検索を除外**（検索クリックの70%が指名）
- **コンバージョン計測を広告に接続**（現在GA4のお問い合わせが各媒体に未連携）

## 7. 章③：予算

### 媒体構成を「成果が出ていた時期」に戻します

|               |     Google広告 |            Meta広告 |           DV360 | お問い合わせ／月 |
| ------------- | -------------: | ------------------: | --------------: | ---------------: |
| 第1期 月平均  | ¥75,000（38%） |      ¥65,000（33%） |  ¥55,000（28%） |        **2.4件** |
| 第2期 月平均  | ¥40,000（16%） |     ¥106,667（42%） | ¥106,667（42%） |           0.67件 |
| **2026年7月** | ¥40,000（17%） | **¥200,000（83%）** |              ¥0 |          **0件** |

**Google広告が半減し、7月はMeta一極集中で0件。** 8月はバランスを戻します。

### 【推奨】集中案 ¥550,000（対7月 +83%）

| 媒体                |       配信費 | 位置づけ                                                    |
| ------------------- | -----------: | ----------------------------------------------------------- |
| Meta広告            |     ¥200,000 | **据え置き**。内訳を地元55%／東京20%／リターゲ25%へ組み替え |
| Google広告（P-MAX） |     ¥100,000 | 第1期水準へ回復。指名検索を除外                             |
| DV360               |      ¥80,000 | 65面を除外して再開                                          |
| LINEヤフー広告      |      ¥60,000 | 既存アカウントを再開（到達率43%の実績）                     |
| 配信費 小計         |     ¥440,000 |                                                             |
| 運用代行費          |     ¥110,000 |                                                             |
| **合計**            | **¥550,000** |                                                             |

**【比較】標準案 ¥450,000（+50%）** — 現行3媒体のみ（Meta ¥200,000／Google ¥80,000／DV360 ¥80,000）

**Metaは減額しません。** 内訳を変えるだけなので、主力媒体を削られる印象を与えずに一極集中を解消できます。
