### 2-1. 会員募集の導線が二重になっています

|              | 会員募集LP                               | 公式サイト                            |

**リンクが一方通行です。** LPから公式サイトへは送客していますが、公式サイトからLPには戻りません。

### 2-4. Google広告の流出率が突出する理由

Google広告（P-MAX）の検索面で、**指名検索を多く拾っています。**

| 検索テーマ                | クリック |
| ------------------------- | -------: |
| 望月 リソル ゴルフ クラブ |       35 |
| リソル 望月               |       11 |
| 望月 東急（旧名称）       |        9 |
| その他                    |       24 |

**指名系だけで検索クリックの70%**を占めます。

その結果、2026年7月のGoogle広告は次の状態です。

|                          |   件数 | セッションに対する比率 |
| ------------------------ | -----: | ---------------------: |
| サイト訪問（セッション） |    396 |                      — |
| フォーム入力開始         |      5 |                  1.26% |
| **公式サイトへ遷移**     | **10** |              **2.53%** |

**フォームに触れる方より、公式サイトへ出て行かれる方が2倍多い状態です。**

「望月リソルゴルフクラブ」と検索された方は、もともと公式サイトをお探しです。その方を広告でLPにお連れし、LPから公式サイトへお送りしている、という循環になっています。

## 3. 改善案

いずれも設定変更または軽微な改修で着手できます。優先順位順です。

### 改善案① 配信エリアをゴルフ場から半径50km圏へ戻す

|                    | 内容                                                                                                                         |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| **根拠**           | 第1期19件のうち53%が半径50〜70km圏（1-4）／最良月2026年3月は半径48〜49km（1-5）／3都県に拡大した7月は0件                     |
| **対象**           | Meta広告の稼働中4広告セット、Google広告 P-MAX                                                                                |
| **内容**           | 配信エリアを半径50〜80kmへ変更。群馬県・埼玉県北部・山梨県をカバー                                                           |
| **東京都の扱い**   | 第1期に6件の実績があるため全面停止はしません。**別広告セットに分離**し、予算とエリアごとの成果を分けて計測できる状態にします |
| **想定される影響** | 配信ボリュームは減少します。ただし現状は集客を1.8倍にして獲得が1/3のため、ボリュームを優先する根拠がありません               |
| **着手**           | 即日可能                                                                                                                     |

### 改善案② DV360（ディスプレイ）の配信面を整理して再開する

DV360は2026年7月1日以降、配信が停止しています（挿入オーダーの期間終了）。**再開を前提に、配信面の整理をご提案します。**

#### 現状：買ったクリックの84%がサイトに到達していません

2026年5〜6月のDV360の実績です。

|                                     |        値 |
| ----------------------------------- | --------: |
| 表示回数                            |   672,105 |
| クリック                            |    43,723 |
| **クリック率（CTR）**               | **6.51%** |
| サイト到達（GA4セッション）         |     6,973 |
| **到達率（セッション ÷ クリック）** | **15.9%** |

ディスプレイ広告のCTRは通常0.1〜0.5%程度です。**6.51%という数値は、広告を見て興味を持ってクリックされたものではなく、誤タップが大半を占めていることを示します。** 実際、クリックの84%はサイトに到達していません。

#### 原因：一部の配信面に偏っています

クリック数の多い配信面です。

| 配信面                 |   表示 | クリック |       CTR | サイト到達率 |  平均滞在 |
| ---------------------- | -----: | -------: | --------: | -----------: | --------: |
| trilltrill.jp          | 88,947 |    7,574 |      8.5% |    **18.5%** | **0.0秒** |
| SmartNews（iOSアプリ） | 23,728 |    4,261 | **18.0%** |        77.6% | **0.9秒** |
| nlab.itmedia.co.jp     | 25,312 |    1,564 |      6.2% |        12.6% |     0.8秒 |
| mamastar.jp            | 23,619 |    1,206 |      5.1% |         4.1% |     0.3秒 |
| ameblo.jp              | 18,075 |      926 |      5.1% |         6.5% |     0.3秒 |

- **trilltrill.jp** — クリック全体の17%を1面で占めますが、**8割がサイトに到達していません**
- **SmartNews（iOSアプリ）** — CTR 18%。到達はしますが**平均0.9秒で離脱**しており、誤タップ後に戻られている状態です

**CTRが5%を超える配信面（表示1,000回以上）は65面あり、これがクリックの61%・配信費の47%を占めています。**

#### 一方で、良質な配信面も存在します

| 配信面                       | サイト到達 | エンゲージ率 |   平均滞在 |
| ---------------------------- | ---------: | -----------: | ---------: |
| MILE mobile（Androidアプリ） |       87件 |    **75.9%** | **28.7秒** |

**アプリ面が一律に悪いわけではありません。** 面ごとの選別が有効です。

> ※ アプリ内ブラウザでは滞在時間が実際より短く計測される場合があります。そのため**判断の主軸は「到達率」**（クリックに対してサイトに到達した割合）に置いています。到達率はこの影響を受けません。

#### ご提案

| #   | 内容                                                                                                                         | 効果                                      |
| --- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| 1   | **CTR異常面の除外リストを作成**（CTR5%超の65面が対象。trilltrill.jp・SmartNews等）                                           | **配信費の47%を、より質の高い面へ再配分** |
| 2   | **最適化目標を「クリック重視」から変更**。現行のラインアイテムは「クリック重視」設定で、誤タップの多い面に予算が寄る構造です | 到達率の改善                              |
| 3   | **良質面のアロウリスト運用へ移行**（MILE mobileのように滞在28.7秒の面を残す）                                                | 面の質を継続的に改善                      |
| 4   | **「到達率」を運用指標に採用**（GA4セッション ÷ クリック。現状15.9%）                                                        | 誤タップを買わない運用へ                  |
| 5   | **DV360側にコンバージョン計測（Floodlight）を設定**                                                                          | 現在DV360単体の成果が測定できていません   |
| 6   | 配信エリアは競合ゴルフ場周辺のジオターゲティングを継続（改善案①と整合）                                                      | —                                         |

**着手**：除外リストの作成は1〜2営業日で可能です。再開のタイミングをご指定ください。

### 改善案③ Google広告から指名検索を分離する

|            | 内容                                                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **根拠**   | 検索クリックの70%が指名検索（2-4）／公式サイトへの流出10件に対しフォーム入力開始5件                                             |
| **内容**   | P-MAXにブランド除外リストを適用し、指名検索を配信対象から外す                                                                   |
| **効果**   | 指名検索は自然検索でも到達できるため、その分の予算を新規開拓に再配分できます                                                    |
| **留意点** | P-MAXは検索・ディスプレイ・動画が一体のため、検索面のみの切り出しはできません。除外設定の可否と配信量への影響を事前に検証します |
| **着手**   | 検証後、1〜2営業日                                                                                                              |

## ご依頼事項

**現時点の「第2期2件」はLP経由のみの集計であり、実際の成果を過小評価している可能性があります。** この点は本資料の前提として明記しておきます。
